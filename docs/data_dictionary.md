# Словарь данных: data/raw/users.csv

Одна строка = один пользователь. Группа назначена один раз и не меняется.

| Столбец | Тип | Описание |
|---|---|---|
| user_id | int | Уникальный ID, растёт со временем регистрации |
| group | str | control (старый Checkout) или treatment (новый) |
| signup_ts | datetime | Момент входа в эксперимент |
| signup_date | date | Дата входа |
| signup_hour | int | Час входа, 0-23 |
| day_of_week | int | День недели, 0 = понедельник |
| is_weekend | int | 1 если суббота или воскресенье |
| device_type | str | mobile / desktop / tablet |
| country | str | US, IN, UK, DE, BR, FR, CA, OTHER |
| traffic_source | str | organic / paid_search / direct / email / social |
| is_new_user | int | 1 если новый пользователь |
| age | int | Возраст, 18-75 |
| sessions_prior_30d | int | Число сессий за прошлые 30 дней |
| cart_items | int | Число товаров в корзине |
| cart_value | float | Стоимость корзины, у (правосторонний разброс) |
| converted | int | 1 если пользователь совершил покупку |
| revenue | float | Выручка, 0 у не купивших |
| purchase_ts | datetime | Время покупки, пусто у не купивших |

## Логичные связи
- Канал трафика зависит от устройства (в соцсетях больше mobile).
- Email приводит в основном вернувшихся пользователей.
- Корзина дороже у desktop и в США, дешевле в Индии и Бразилии.
- Конверсия выше у desktop, у вернувшихся и у email-канала.
- Выручка = стоимость корзины с шумом, только у купивших.

## Что НЕ хранится в датасете
Истинный эффект лежит отдельно в data/simulation/truth.json (в Git не попадает).
Он нужен только для проверки симуляции и не используется в аналитике.
