# Расширенные методы ExperimentLab

Эффект Δ = (T) − (C). Решение принимается по первичной метрике (конверсия) при выполнении ВСЕХ заранее заданных критериев. Значимость одной метрики не равна успеху эксперимента.

## 1. SRM (Sample Ratio Mismatch)
**Математика.** $\chi^2=\sum_g (O_g-E_g)^2/E_g$, $E_T=n\,s_T$, одна степень свободы. Порог p < 0,001. По сегментам и дням порог делится на число проверок (Bonferroni).
**Бизнес.** SRM означает, что группы набирались не так, как планировалось: баг назначения, потеря данных, боты. При SRM любые результаты недостоверны.
- Правильно: «SRM обнаружен, остановить интерпретацию, искать причину; смотреть, в каком сегменте или дне перекос».
- Неправильно: «SRM есть, но эффект же значим, значит, всё нормально» или «пересчитаем с поправкой на размер групп».

## 2. Bootstrap
**Математика.** B пересэмплирований с возвращением, статистика на каждом, интервал = квантили α/2 и 1−α/2 (percentile). Для долей: $\text{Bin}(n,\hat p)/n$ (эквивалентно пересэмплированию нулей и единиц). Воспроизводимость задаётся seed.
**Бизнес.** Независимая от нормальности проверка аналитического интервала, особенно для выручки с тяжёлым хвостом.
- Правильно: «bootstrap-интервал близок к аналитическому, вывод не зависит от метода».
- Неправильно: «bootstrap даёт больше значимости, чем тест, возьмём его» (выбор метода по результату) и «увеличим число повторений, пока интервал не станет узким» (повторения уменьшают шум симуляции, а не неопределённость данных).

## 3. Сегментный анализ
**Математика.** Z-тест долей в каждом уровне заранее заданных признаков; все тесты образуют одно семейство. Омнибус-тест гетерогенности: $LR=2(\ell_{T\times S}-\ell_{T+S})\sim\chi^2_{k-1}$. Сегменты меньше порога размера не тестируются.
**Бизнес.** Показывает, где эффект может отличаться, и что проверить следующим тестом.
- Правильно: «в сегменте X разница +2 п.п., но после поправки на 23 сравнения она не подтверждена; гипотеза для отдельного теста».
- Неправильно: «в сегменте X p = 0,03, запускаем только для X» (выбор лучшего из многих). Нельзя добавлять сегменты после просмотра результатов.

## 4. Множественные сравнения
**Математика.** Без поправки $P(\ge 1\text{ ложная находка})=1-(1-\alpha)^m$ (m = 20: 64%). Bonferroni: $\tilde p=\min(1,mp)$ (FWER). Holm: шаговая, мощнее Bonferroni. BH: $\tilde p_{(i)}=\min_{j\ge i} m p_{(j)}/j$ (FDR).
**Бизнес.** Решения о запуске принимаются по FWER (Holm). BH годится для списка идей, где допустима доля ложных находок.
- Правильно: «из 23 сегментов 4 значимы без поправки, 1 по BH, 0 по Холму; решение не меняется».
- Неправильно: «значимых сегментов 4, значит, у эффекта сегментная структура».

## 5. Guardrail-метрики
**Математика.** Тест non-inferiority: PASS, если нижняя односторонняя граница эффекта (в шкале «больше = лучше») выше −δ; FAIL, если верхняя граница ниже −δ; иначе INCONCLUSIVE.
**Бизнес.** Рост конверсии не должен покупаться падением чека, выручки или ростом возвратов.
- Правильно: «ARPU: нижняя граница −1,2% лучше допустимых −5%, guardrail пройден»; «возвраты не измерены, статус NOT_EVALUATED, запуск с мониторингом».
- Неправильно: «ARPU изменился незначимо, значит, он не пострадал» (отсутствие значимости не доказывает отсутствие вреда) и «возвраты не измеряли, значит, всё хорошо».

## 6. Анализ чувствительности
**Математика.** Заранее заданный набор методов на один вопрос (z / bootstrap / регрессия с ковариатами до эксперимента; Уэлч / bootstrap / винзоризация). Устойчиво, если все дают одно решение и один знак. Другие оценки (Манн-Уитни, лог-выручка) отвечают на другой вопрос и в вердикт не входят.
**Бизнес.** Проверка, что вывод не держится на выбросах или выбранном тесте.
- Правильно: «после ограничения чеков на 99% оценка ARPU почти не изменилась; эффект не зависит от нескольких крупных заказов».
- Неправильно: «без выбросов значимо, уберём их из отчёта» (удалять выбросы по результату нельзя; винзоризация только проверка).

## 7. Качество эксперимента
**Математика.** $SMD=(\bar x_T-\bar x_C)/\sqrt{(s_T^2+s_C^2)/2}$; ориентиры 0,10 / 0,25. Достаточность: n против плана и MDE на факте. Длительность: целые недели, ≥ 2 недель, без пропусков. Стабильность: один тест разницы эффектов первой и второй половины.
**Бизнес.** Позволяет отличить «эффекта нет» от «эксперимент провели плохо».
- Правильно: «MDE на факте 0,53 п.п. выше порога 0,5 п.п.: тест может не заметить минимально значимый эффект, это ограничение вывода».
- Неправильно: «мощность по полученному эффекту 95%, значит, данных хватало» (наблюдаемая мощность однозначно выражается через p-value) и «эксперимент остановили на второй день, потому что p < 0,05» (подглядывание).

## Итоговое решение
SHIP возможен только при: SRM пройден; нет критических проблем качества; конверсия значима и практически значима; guardrail не ухудшились; результат устойчив; нет подтверждённого вреда в сегментах; обязательные guardrail измерены. Положительные сегменты решение улучшить не могут.
