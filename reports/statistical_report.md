## Приложение: методы и формулы

Обозначения: C = control, T = treatment, эффект Δ = (значение в T) − (значение в C), α = уровень значимости.

## 0. План анализа (фиксируется до просмотра результатов)

| Метрика | Роль | Тест |
|---|---|---|
| Конверсия | первичная, по ней принимается решение | z-тест двух долей, двусторонний |
| ARPU | вторичная | тест Уэлча |
| ARPU | проверка устойчивости | bootstrap-интервал |
| Распределение выручки | диагностика | Манн-Уитни (проверяет другую гипотезу) |

Все результаты показываются независимо от исхода. Тест не выбирается по результату: это защита от p-hacking.

## 1. Конверсия: z-тест двух долей

Для группы g: $\hat p_g = x_g / n_g$, где $x_g$ число покупателей. Эффект: $\hat\Delta = \hat p_T - \hat p_C$.

Если H0 верна, доли равны, поэтому для оценки дисперсии объединяем группы:

$$\hat p = \frac{x_C + x_T}{n_C + n_T}, \qquad SE_0 = \sqrt{\hat p (1-\hat p)\left(\frac{1}{n_C} + \frac{1}{n_T}\right)}, \qquad z = \frac{\hat\Delta}{SE_0}$$

p-value: двусторонний $2\,(1 - \Phi(|z|))$; односторонний (H1: $p_T > p_C$) $1 - \Phi(z)$.

Доверительный интервал (под альтернативой доли различаются, поэтому SE раздельная):

$$SE_1 = \sqrt{\frac{\hat p_C(1-\hat p_C)}{n_C} + \frac{\hat p_T(1-\hat p_T)}{n_T}}, \qquad \hat\Delta \pm z_{1-\alpha/2}\, SE_1$$

Относительный прирост: $\hat p_T / \hat p_C - 1$. Интервал строится для логарифма отношения (метод Катца):

$$SE_{\ln RR} = \sqrt{\frac{1-\hat p_T}{x_T} + \frac{1-\hat p_C}{x_C}}, \qquad RR \in \exp\left(\ln \hat{RR} \pm z_{1-\alpha/2}\, SE_{\ln RR}\right)$$

**Почему не t-тест.** Конверсия это бинарная величина, её дисперсия $p(1-p)$ определяется самой долей. Тест долей использует это знание, а t-тест оценивал бы дисперсию заново.

**Предпосылки.** Наблюдения независимы (одна строка на пользователя, группа назначена один раз); в каждой группе не менее 10 успехов и 10 неудач (нормальное приближение); соотношение групп соответствует плану (SRM).

## 2. Проверка SRM

$$\chi^2 = \sum_g \frac{(n_g - E_g)^2}{E_g}, \quad E_T = n \cdot s_T,\; E_C = n - E_T$$

Одна степень свободы. Порог строгий (p < 0,001), потому что SRM означает поломку эксперимента, а не «небольшое отклонение».

## 3. Выручка

**ARPU** = общая выручка / все пользователи (включая нулевых). **ARPPU** = общая выручка / только покупатели.
$ARPU = \text{конверсия} \times ARPPU$.

**ARPPU сравнивать с осторожностью.** Покупатели отбираются ПОСЛЕ назначения группы, и если дизайн меняет, кто покупает, то группы покупателей перестают быть сравнимыми. Поэтому ARPPU описательный, а вывод о выручке делается по ARPU.

**Тест Уэлча** (не требует равенства дисперсий):

$$t = \frac{\bar y_T - \bar y_C}{\sqrt{s_C^2/n_C + s_T^2/n_T}}, \qquad \nu = \frac{(a+b)^2}{a^2/(n_C-1) + b^2/(n_T-1)},\; a = \frac{s_C^2}{n_C},\; b = \frac{s_T^2}{n_T}$$

Интервал: $\hat\Delta \pm t_{1-\alpha/2,\nu}\,SE$.

**Асимметрия и нули.** Выручка = масса в нуле (около 90%) + тяжёлый правый хвост. Тест Уэлча сравнивает средние и остаётся применимым при больших n благодаря центральной предельной теореме. Ориентир (Cochran, Sugden и др.): $n \ge 28 + 25\gamma_1^2$, где $\gamma_1$ асимметрия. Это эвристика, поэтому результат всегда подкрепляется bootstrap.

**Bootstrap** (percentile): B раз пересэмплируем каждую группу с возвращением, считаем разницу средних, берём квантилы $\alpha/2$ и $1-\alpha/2$ распределения этих разностей. Не требует нормальности.

**Манн-Уитни** проверяет, равна ли $P(Y_T > Y_C) + 0.5\,P(Y_T = Y_C)$ значению 0,5. Это про сдвиг распределения целиком, а НЕ про среднее. При множестве нулей и разных хвостах его результат может не совпасть с тестом на среднем, и это не противоречие, а другой вопрос. Поэтому в решении он не участвует.

## 4. Проверка гипотез: терминология

- **H0** нет эффекта, **H1** эффект есть. Тест двусторонний, потому что новый дизайн может и ухудшить метрику. Односторонний тест допустим только если направление заранее обосновано, и результат не должен выбираться после просмотра данных.
- **Ошибка I рода** (ложная находка): вероятность = α.
- **Ошибка II рода** (пропуск реального эффекта): вероятность β = 1 − мощность.
- **p-value** вероятность получить данные не менее экстремальные, чем наблюдаемые, если H0 верна. Это НЕ вероятность того, что H0 верна.
- **p > α** означает «данные не противоречат H0 достаточно сильно». Это не доказательство H0. Для вывода «эффекта практически нет» используется доверительный интервал целиком внутри допустимой зоны.
- **Статистическая значимость** (p < α) говорит, что разницу трудно объяснить шумом. **Практическая значимость** говорит, что разница достаточно велика, чтобы окупить внедрение. При большой выборке значима бывает и ничтожная разница.

## 5. Правило практической значимости

Порог $\tau$ задан бизнесом. Классификация по интервалу $[L; U]$:

| Условие | Вывод |
|---|---|
| p < α, Δ > 0, $L \ge \tau$ | значим статистически и практически |
| p < α, Δ > 0, $L < \tau \le U$ | значим, практическая значимость не подтверждена |
| p < α, Δ > 0, $U < \tau$ | значим, но практически ничтожен |
| p < α, Δ < 0 | значимое ухудшение |
| p ≥ α, $-\tau < L$ и $U < \tau$ | значимости нет, практически значимый эффект не поддерживается |
| p ≥ α, иначе | неопределённо, данных недостаточно для вывода |

Предпоследняя строка использует логику эквивалентности: вывод опирается на интервал, а не на p > α.

## 6. Мощность и размер выборки

Мощность z-теста долей (двусторонний, $\delta = p_T - p_C$):

$$\text{power} = \Phi\!\left(\frac{|\delta| - z_{1-\alpha/2}\,SE_0}{SE_1}\right) + \Phi\!\left(\frac{-|\delta| - z_{1-\alpha/2}\,SE_0}{SE_1}\right)$$

Размер выборки при равных группах (контрольная группа):

$$n = \frac{\left(z_{1-\alpha/2}\sqrt{2\bar p\bar q} + z_{1-\beta}\sqrt{p_C q_C + p_T q_T}\right)^2}{\delta^2}$$

В коде $n$ находится численно решением уравнения «мощность = цель», это работает и при неравных группах.

**MDE** минимальный эффект, который тест с заданным $n$ обнаружит с целевой мощностью (решение того же уравнения относительно $\delta$).

**Для средних** (ARPU): $n = \sigma^2 (1 + 1/r)(z_{1-\alpha/2} + z_{1-\beta})^2 / \delta^2$ и $\delta_{MDE} = (z_{1-\alpha/2} + z_{1-\beta})\,\sigma\sqrt{(1+1/r)/n}$.

**Длительность** = $n_{total} / \text{пользователей в день}$, округлённая вверх до целых недель (чтобы в тест попали все дни недели поровну).

**Мощность после эксперимента.** Считать «наблюдаемую мощность» по полученному эффекту нельзя: она однозначно выводится из p-value и ничего нового не сообщает. Вместо этого считаются мощность для планового эффекта и MDE на фактическом объёме.

## 7. Множественные сравнения

Каждый дополнительный тест на тех же данных повышает шанс ложной находки. Поэтому первичная метрика одна, а при анализе сегментов применяется поправка Холма.
